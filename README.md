# 大模型横评 (llm-benchmark)

本仓库收录我做的各种**大模型测试与横评项目**：每个项目包含任务考题（提示词）、评分标准，以及各模型的实测成果。

## 目录说明

```
llm-benchmark/
├── README.md                    # 本文件：仓库说明与成果汇总
├── 六足送咖啡任务提示词.md        # 考题 01：六足机器人送咖啡仿真任务规划
└── results/                     # （按需创建）各考题的实测成果与原始回答
```

**考题文件约定**：每个横评项目一个 Markdown 文件，文件名即考题名（如「××任务提示词.md」），内含：

1. **任务提示词**——可直接复制发给被测模型的完整提示词；
2. **评分标准**——分维度、分值的打分细则。

## 评测流程

1. 打开考题文件，复制其中的「任务提示词」**原样**发给被测模型（同一考题对各模型保持一致，温度等参数如有特殊设置则在成果中注明）；
2. 按该文件的「评分标准」逐项打分，记录扣分原因；
3. 成果写入 `results/` 对应文件（或直接在下方「成果汇总」中登记），保留模型原始回答以便复查。
