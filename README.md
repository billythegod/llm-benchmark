# 大模型横评 (llm-benchmark)

本仓库收录我做的各种**大模型测试与横评项目**：每个项目包含任务考题（提示词）、评分标准，以及各模型的实测成果。

## 目录说明

**每个横评项目一个独立文件夹**，内含该项目的考题（提示词）与各模型的成果文件：

```
llm-benchmark/
├── README.md                       # 本文件：仓库说明与成果汇总
└── 六足机器人送咖啡/                 # 项目 01：六足机器人送咖啡仿真任务规划
    ├── 六足送咖啡任务提示词.md        # 考题：任务提示词 + 评分标准
    └── <模型名>.html                 # 各模型的最终离线成果（文件名 = 模型/参评名）
```

**考题文件约定**：每个项目的考题是一个 Markdown 文件，内含：

1. **任务提示词**——可直接复制发给被测模型的完整提示词；
2. **评分标准**——分维度、分值的打分细则。

**成果文件约定**：每个被测模型一个自包含（可离线双击打开）的 HTML，以模型/参评名命名，放入对应项目文件夹。

## 评测流程

1. 打开项目文件夹中的考题文件，复制其中的「任务提示词」**原样**发给被测模型（同一考题对各模型保持一致，温度等参数如有特殊设置则在成果中注明）；
2. 按该文件的「评分标准」逐项打分，记录扣分原因；
3. 各模型的最终成果（自包含离线 HTML）以模型名命名放入项目文件夹，并在下方「成果汇总」中登记，保留原始回答以便复查。

## 如何新增横评项目

在仓库根目录新建一个项目文件夹（文件夹名即项目名），参照 [六足机器人送咖啡/](./六足机器人送咖啡/) 的结构放入考题 Markdown 与各模型成果 HTML，并在本 README 的「考题列表」与「成果汇总」中登记即可。
